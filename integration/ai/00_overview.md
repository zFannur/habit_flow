# AI Module — Обзор и план улучшений

## Текущее состояние

AI-модуль охватывает 3 вкладки: **Чат**, **Сводки**, **Промпты** + **Настройки ИИ**.

### Обнаруженные проблемы

| # | Severity | Описание |
|---|----------|----------|
| 1 | 🔴 Критич. | Markdown в чате — кастомный парсер поддерживает только `**bold**` и `` `code` ``. Нет заголовков, списков, курсива. ИИ отвечает в полноценном Markdown, но он рендерится как plain text. |
| 2 | 🔴 Критич. | Сводку нельзя вызвать вручную — кнопка «Regenerate» и «Ask about this summary» в `summary_detail_screen.dart` имеют пустой `onTap: () {}`. |
| 3 | 🔴 Критич. | Промпты (14 шт.) полностью захардкожены в `prompts_grid_screen.dart`, нельзя добавить/удалить/редактировать. |
| 4 | 🔴 Критич. | Usage-секция в AI Settings вся на моках: `today=23`, `limit=200`, `spent=$0.00`. |
| 5 | 🟡 Средн.  | Disclaimer показывается каждый сеанс (`_disclaimerVisible = true` в state). Нужно показать 1 раз, потом сохранить флаг. |
| 6 | 🟡 Средн.  | Стрим текста: механизм стриминга в `ChatController` и `OpenRouterClient` реализован и рабочий (SSE), но `_Markdown` виджет при стриминге рендерит raw-текст вместо markdown. |
| 7 | 🟡 Средн.  | Счётчик сообщений: в `_InputBar` (chat_screen.dart:1030) хардкод модели `gpt-oss-120b:free` и лимит 200. В AI Settings usage тоже хардкод. |
| 8 | 🟡 Средн.  | Быстрые промпты в чате (5 шт.) захардкожены на русском. |
| 9 | 🟡 Средн.  | Заголовок чата `'ИИ'` и бейдж `'🎓 Coach'` — не меняется при смене стиля. |
| 10 | 🟢 Низк.  | Стиль: имена/описания/превью захардкожены на русском в `ai_settings_screen.dart`. |

## Шаги реализации

Каждый шаг — отдельный markdown-файл и один коммит.

### Шаг 01 — Полноценный Markdown-рендеринг в чате
**Файл:** `01_chat_markdown_renderer.md`

Заменить кастомный `_Markdown` виджет в `chat_screen.dart` на полноценный рендерер с поддержкой: заголовков (H1-H6), списков (булеты + нумерованные), **bold**, *italic*, `inline code`, блоков кода (```) и ссылок.

Вариант A: Использовать существующий `_MarkdownBody` из `summary_detail_screen.dart` (он уже поддерживает всё это) — вынести в shared-виджет.
Вариант B: Добавить пакет `flutter_markdown` (зависит от flutter_secure_storage web-совместимости).

**Рекомендация**: Вариант A — вынести `_MarkdownBody` из `summary_detail_screen.dart` в `shared/widgets/hf_markdown.dart` и переиспользовать в чате.

---

### Шаг 02 — Disclaimer «Твой ключ — твои данные» один раз
**Файл:** `02_disclaimer_once.md`

Сейчас `_disclaimerVisible = true` сбрасывается при каждом входе в чат. `DisclaimerService` уже есть и используется для модального диалога при входе на вкладку. Нужно:

1. В `chat_screen.dart` при `initState` читать `disclaimerService.hasSeen()`.
2. Если `seen == true` → `_disclaimerVisible = false`.
3. При нажатии «Понятно» → вызывать `disclaimerService.markSeen()`.
4. Убрать дублирование: модальный диалог (`PrivacyDisclaimerDialog`) из `ai_screen.dart` больше не нужен — оставить inline-баннер в чате как единственную точку показа.

---

### Шаг 03 — Реальные данные usage (счётчик сообщений)
**Файл:** `03_usage_real_data.md`

1. В `_InputBar` (chat_screen.dart): убрать хардкод `_requestsLimit = 200`, модель `'gpt-oss-120b:free'`. Вместо этого — читать выбранную модель из `preferredModelControllerProvider`.
2. В `ai_settings_screen.dart` (Usage-секция): подключить `dailyMessageCountProvider` вместо моков `today=23`, `limit=200`.
3. Месячную статистику и расход `$0.00` — пока пометить как «скоро» или скрыть секцию, т.к. бэкенд не возвращает эти данные.

---

### Шаг 04 — Ручной вызов сводки + кнопка «Спросить про сводку»
**Файл:** `04_manual_summary.md`

В `summary_detail_screen.dart`:

1. **«Ask about this summary»**: При нажатии — скопировать контент сводки в `pendingPromptProvider` как «Разбери эту сводку подробнее: ...» и перейти на вкладку Чат.
2. **«Regenerate»**: Вызвать Edge Function `generate_summary` с текущим `rangeStartN` / `rangeEndN`. Показать лоадер, заменить содержимое по завершению.

Опционально: На экране `SummariesScreen` добавить кнопку «Создать сводку сейчас» (если условие 30 записей выполнено).

---

### Шаг 05 — Пользовательские промпты (добавление/удаление)
**Файл:** `05_custom_prompts.md`

Сейчас 14 промптов захардкожены в `prompts_grid_screen.dart`. Нужно:

1. Создать таблицу `ai_prompts` в Supabase: `id`, `user_id`, `emoji`, `title`, `description`, `category`, `is_system`, `position`.
2. Предзаполнить `is_system = true` для встроенных промптов (локализация через ARB, не БД).
3. Добавить FAB «+» на экране промптов → диалог создания (emoji, название, описание, категория).
4. Свайп для удаления пользовательских промптов (системные — нельзя удалить).
5. Репозиторий: `AiPromptsRepository` с CRUD + `watchAll()`.

---

### Шаг 06 — Динамический бейдж стиля в заголовке чата
**Файл:** `06_dynamic_style_badge.md`

В `_Header` (chat_screen.dart):
1. Убрать хардкод `'ИИ'` → использовать `l.aiScreenTitle`.
2. Убрать хардкод `'🎓 Coach'` → читать текущий `AiStyle` из `aiStyleControllerProvider` и показывать соответствующий emoji + название стиля.

---

### Шаг 07 — Локализация промптов и стилей
**Файл:** `07_localize_prompts_styles.md`

1. Перенести 5 быстрых промптов в `chat_screen.dart` в ARB.
2. Перенести 14 карточек промптов (`prompts_grid_screen.dart`) в ARB.
3. Перенести имена/описания/превью стилей из `ai_settings_screen.dart` в ARB.
4. Перенести захардкоженные русские строки из `prompt_builder.dart` (identity statement instruction) в ARB.

## Порядок реализации

```
01 → Markdown рендеринг (самое заметное улучшение UX)
02 → Disclaimer один раз (быстрый фикс)
03 → Usage реальные данные (убрать моки)
04 → Ручная сводка (восстановить функционал)
05 → Пользовательские промпты (новый функционал)
06 → Бейдж стиля (косметика)
07 → Локализация (финальный pass)
```

## Валидация каждого шага

1. `flutter analyze` — без ошибок.
2. Визуальная проверка: открыть чат, отправить сообщение ИИ, убедиться в корректном рендеринге.
3. Коммит: `git commit -m "feat(ai): <описание шага>"`.
