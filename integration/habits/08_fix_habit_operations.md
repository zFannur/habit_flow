# Шаг 08 — Исправление ошибок работы с привычками и расширение функционала редактирования

**Severity:** 🟡 MEDIUM · **Время:** 45 мин · **Риск:** средний.

## Проблемы

1. **Дублирование привычек при добавлении**: Иногда после создания новой привычки она отображается дважды в списке `HabitsListScreen` или `TodayScreen`. После перезагрузки дубликат пропадает.
2. **Ограниченный экран редактирования**: При нажатии "Редактировать" в `HabitDetailScreen` открывается `HabitFormScreen`, но он принудительно перескакивает на Шаг 2 (`_step = 2`), лишая пользователя возможности изменить тип привычки (Build/Quit/etc).
3. **Не загружаются фото**: Для отображения фотографий из Telegram используется Edge Function `get_telegram_photo`. Однако в компоненте `Image.network` не передается `Authorization` заголовок, из-за чего функция возвращает 401/403.
4. **Прочие баги**: Потенциальные race conditions при сохранении, проблемы с локализацией и форматированием.

## План действий

### 1. Исправление дубликатов в списке привычек

В `lib/features/habits/data/habits_providers.dart` `habitsStreamProvider` напрямую транслирует события от `Supabase.stream`. Иногда локальные кэши и серверные события приходят с задержкой, вызывая дублирование. Необходимо добавить дедупликацию по `id`.

**Файл: `lib/features/habits/data/habits_providers.dart`**
Изменить `watchAll` в `habits_repository.dart` или маппинг в провайдере для удаления дубликатов.

### 2. Полноценный экран редактирования

В `HabitFormScreen` убрать хардкод `_step = 2` при инициализации редактирования. Разрешить пользователю менять `type`, начиная с 1 шага.

**Файл: `lib/features/habits/presentation/habit_form_screen.dart`**
- В `initState()`:
  ```dart
  // Убрать setState(() { _step = 2; });
  ```
- В `_canNext()` и `_back()` убрать ограничения, связанные с `widget.habitId != null`.

### 3. Исправление загрузки фото (Авторизация)

Supabase Edge Functions требуют передачи JWT токена текущего пользователя.

**Файлы: `habit_form_screen.dart` и `habit_detail_screen.dart`**
При использовании `Image.network` необходимо добавлять `headers`:
```dart
Image.network(
  '${Env.supabaseUrl}/functions/v1/get_telegram_photo?file_id=${widget.iconTelegramFileId}',
  headers: {
    'Authorization': 'Bearer ${Supabase.instance.client.auth.currentSession?.accessToken}',
  },
  // ...
)
```

### 4. Комплексная проверка и фиксы

- Проверить `habits_list_screen.dart` на правильное использование ключей для анимаций (важно для Swipe to Archive/Delete).
- Убедиться, что при создании привычки очищается драфт (`habitDraftProvider.notifier.reset()`), чтобы предотвратить случайное переиспользование данных.

## Валидация

1. Создать новую привычку -> убедиться, что она появляется в списке один раз.
2. Открыть привычку -> Редактировать -> убедиться, что открывается Шаг 1 с выбором типа.
3. Добавить `file_id` -> проверить загрузку изображения с токеном.
